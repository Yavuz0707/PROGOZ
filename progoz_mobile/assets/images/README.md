# Uygulama görselleri

## PROGÖZ logosu

Uygulama logosunu buraya **tam olarak şu adla** kaydet:

```
assets/images/progoz_logo.png
```

- Önerilen: kare veya yatay PNG, **şeffaf arka plan** (login ekranı koyu zemin),
  en az ~512 px genişlik.
- Dosya konunca login ekranında otomatik görünür (kod hazır).
- Dosya yoksa uygulama kırılmaz; geçici olarak çerçeveli güvenlik ikonu gösterilir.

> Not: Uygulama teması monokrom (siyah-beyaz). Renkli/gradyanlı logo, login
> ekranında bilinçli bir marka vurgusu olarak kullanılır.

## Uygulama simgesi (app icon) — opsiyonel

Açılış/launcher simgesini de logodan üretmek istersen, logoyu kaydettikten sonra
`flutter_launcher_icons` ile tek komutta tüm boyutlar üretilebilir (söyle, ayarlarım).
